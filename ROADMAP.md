# Дорожная карта IDS Core

Обновлено 8 ноября 2026 года. Статус «Доступно» проверен по опубликованному просмотрщику. Этот список помогает обсуждать развитие проекта; даты выпуска для предложений пока не назначены.

## Доступно

- Открытие нескольких IFC, поиск по ID и названию, просмотр свойств.
- Дерево модели и избранные элементы.
- Проверка по IDS, встроенные наборы требований.
- Проверка площадей ТЭП с XML и экспорт отчёта.
- Сравнение версий IFC по геометрии и параметрам.
- Поиск дублей, загрузка отчётов и удаление выбранного дубля.
- Проверка коллизий и обрезка поддерживаемых элементов ПС/БиО.
- Изменение параметров, классов и этажей; переименование и исключение уровней.
- Вторая плоскость разреза по запросу.
- Скриншоты со стрелками, рамками и подписями.
- Сводка перед сохранением и передача журнала правок JSON.
- Вертикальная панель управления видом.

## Обсуждаем

| Идея | Зачем | Статус |
|---|---|---|
| Сохранённые виды | Возвращаться к нужной камере, разрезу и видимости | Собираем сценарии использования |
| Таблица элементов | Сопоставлять параметры и переходить из строки к объекту | Предложение |
| Проверка заполненности | Находить элементы с пустыми обязательными параметрами | Предложение |

Обсуждаемые функции пока не находятся в разработке. Приоритет выбираем по реальным задачам пользователей.

## Как повлиять на планы

[Предложите функцию](https://github.com/1skyrill1/ids-core-community/issues/new?template=feature_request.yml): что приходится делать вручную, какой результат нужен, как часто возникает задача. Можно описать сценарий существующего предложения. Пример на учебной модели помогает понять задачу быстрее.
