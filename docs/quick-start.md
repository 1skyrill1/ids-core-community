# С чего начать

## Просмотрщик IFC

1. Откройте [просмотрщик IDS Core](https://idscore.online/viewer.html).
2. Перетащите IFC в окно. Для первого знакомства можно открыть [учебную модель](https://idscore.online/viewer.html?demo=1).
3. Нажмите на элемент, чтобы посмотреть его свойства. Списки моделей, классов и этажей расположены слева.
4. Выберите инструмент для своей задачи. После применения правок нажмите «Сохранить IFC», чтобы скачать результат.

Подробные сценарии доступны на сайте.

- [Проверить модель по IDS](https://idscore.online/proverka-ifc-po-ids.html)
- [Найти элементы по параметру](https://idscore.online/filtr-ifc-po-parametram.html)
- [Сравнить версии IFC](https://idscore.online/sravnenie-ifc.html)
- [Проверить площади ТЭП](https://idscore.online/proverka-ploshchadej-tep.html)
- [Найти дубли](https://idscore.online/dubli-ifc.html)
- [Разобрать коллизии](https://idscore.online/kollizii-ifc-online.html)
- [Изменить этажи](https://idscore.online/etazhi-ifc.html)
- [Передать журнал правок](https://idscore.online/pravki-ifc-fajlom.html)

## Плагин для Revit

Порядок установки и первое открытие описаны в [инструкции по установке](https://idscore.online/docs/install.html). Для проверки модели добавьте файлы IDS и следуйте [инструкции по проверке](https://idscore.online/docs/validator.html).

## Если что-то пошло не так

Откройте [новое обращение](https://github.com/1skyrill1/ids-core-community/issues/new/choose) и выберите сообщение об ошибке. Укажите версию Revit или браузера, последовательность действий и ожидаемый результат. Проверьте, повторяется ли проблема на учебной модели.
